# Atualização — conteúdo dentro dos módulos

## O que mudou
- Os flashcards genéricos foram removidos.
- Agora os flashcards testam conceitos reais de cada módulo.
- Cada módulo possui um resumo didático dentro do próprio site.
- Cada módulo possui pontos-chave para a prova.
- Continuam visíveis: o que dominar, como estudar e foco de revisão.
- A área “Onde estudar” agora possui links clicáveis.
- O Guia Por Dentro da B3 e a página oficial da PQO ficam disponíveis diretamente no módulo.
- Alguns capítulos também possuem cursos específicos da B3 Educação.

## Como atualizar no seu computador
Se você ainda não fez alterações próprias no projeto anterior:
1. baixe o novo ZIP;
2. extraia;
3. abra a pasta `pqo-study-conteudo` no VS Code;
4. abra `index.html` com Live Server.

Se você já configurou o Supabase no projeto anterior:
1. abra o `config.js` antigo;
2. copie apenas os dois valores do Supabase;
3. cole esses valores no `config.js` da nova versão;
4. NÃO cole a `service_role` key.

## Observação
Os resumos são didáticos e servem para estudo. Para regras, prazos e detalhes normativos, a fonte oficial indicada no módulo deve prevalecer.
